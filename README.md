# Para Paula

Juego cívico con datos de Ecuador 2000-2026: adivina primero y mira el dato real, con su fuente.

Vista previa, mientras se define el dominio. Los datos vienen de organismos internacionales (Banco Mundial, FMI, OIT, UNODC,
PNUD, V-Dem, Freedom House, Transparencia Internacional, EIA) y, para los casos de corrupción, de documentos de la Fiscalía,
la Contraloría y cortes de EE. UU. Cada cifra en la página enlaza a su fuente.

La página no pide cuenta ni datos personales: el progreso queda en el teléfono de cada persona.
